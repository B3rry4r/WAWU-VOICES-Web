# Design boards for this check

The owner's boards, as markup (`.dc.html`) and as pictures (`.png`, the first screen only: a phone board is a 390x844 frame that scrolls inside).
To see the rest of a board, open the `.dc.html` file in Playwright with a `file://` address from this folder (it needs `ds/` and `support.js`, which are here) and scroll inside the frame.
The logo picture is missing in these renders: ignore that.
Boards are the authority for layout, words and flow. They are not the authority for prices, limits or legal text.
The boards draw an OPEN question and a RUNNING topic. No board draws the "not open yet" state: that state is the owner's instruction of 14 Nov 2026.
